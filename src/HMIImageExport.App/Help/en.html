Quick start

  1. Enter host/IP, port (usually 5900) and password of the panel at the top and click Connect.
  2. The panel image appears. A mouse click in the image acts like a finger tap on the panel.
  3. Open a page on the panel and press F9. Enter a page name; the image is saved immediately.
  4. Capture all pages, check the order, then click Create Word ….

Connect to panel

VNC access must be enabled on the panel (on Siemens panels this is the Sm@rtServer; the setting depends on the panel and the engineering tool). Enter host/IP, port and password as you would in the UltraVNC viewer.

For several panels, create a connection profile in the settings and select it at the top under “Profile”.

Many panels allow only one connection at a time: close an open UltraVNC viewer first.

Plant folder

All images of a plant are stored in one folder, for example Anlage1. The folder is chosen on the first save or via File › Open (Ctrl+O). An existing folder is loaded with its page list (file pages.json).

Capture pages

F9 or Save page saves the current panel image in original resolution as PNG, for example 01_Start_2026-11-26_1432.png. The image is taken at the moment you press the key; the page name is asked afterwards.

Page list

  • Rename: changes page name and file name.
  • Retake: replaces the image of the selected page with the current panel image.
  • Remove: deletes the page and its image file (with confirmation).
  • Order: drag & drop, ▲/▼, or Alt+↑/↓. The list order is used for Word.

Capture several languages

If the panel has several languages that are switched with a language button (e.g. the flag at the top), the tool captures every page in all languages automatically.

  1. In the Multilingual area, enter the languages as short codes in the order of the language button, e.g. DE, EN, FR. The number follows from the list.
  2. The panel currently shows: select the language that is displayed right now.
  3. Click Set language button and then click the language button once in the panel image. Use Test switching to check that the panel changes to the next language.
  4. Enable Capture all languages. Then press F9: the tool saves the current language, clicks the button, waits until the image is quiet, saves the next language, and so on, and finally switches back to the original language.

File names contain the code, e.g. 02_Seite_2_EN_2026-11-26_1501.png. A page with all its languages shares one number; renaming applies to all languages of the page. In Word, all languages of a page follow each other, and the caption names the language.

Method (Settings › Multilingual capture): currently each click on the language button switches to the next language. If the image does not change after switching, the tool reports the affected language; then check the language button and the quiet time.

Create Word

Inserts all images of the list one after another into a new .docx, one image per page, scaled to page width. Word does not need to be installed.

  • Caption: “page name · plant · date” below each image.
  • Cover page: title, plant, date and optional project number.
  • Landscape: A4 landscape (recommended for panel images) or portrait.

Default name: Anlage1_Touchpanel_2026-11-26.docx. The images are embedded in the document.

Settings

Connection profiles (name, host, port, password) are managed here. The data is stored in %APPDATA%\HMIImageExport\settings.json. Help › Open settings folder takes you there. The language is switched via View › Language.

Troubleshooting

  • “Unsupported encoding (number)”: The panel sends a format the tool does not know. Please report the number.
  • Image visible, clicks have no effect: You probably used the view-only password. Enter the password for full control.
  • Login failed: Check the password. VNC passwords are limited to 8 characters.
  • Timeout / cannot connect: Check IP, port, network and firewall. Check that VNC access is enabled on the panel and that no other connection (e.g. UltraVNC viewer) is open.
  • Word file cannot be saved: If it is still open in Word, close it or choose another name.

Installation

The program is portable: unpack the ZIP file and start HMIImageExport.exe. No installation and no .NET are required. To remove it, delete the folder; settings are stored separately in %APPDATA%\HMIImageExport.

Passwords and security

Passwords are stored encrypted only (Windows data protection API, bound to your Windows user account) and never in clear text in the file or the log. A copied settings.json does not work on another PC or user; the password must be entered again there.

VNC protects the password only weakly and transmits images unencrypted. Use connections only inside the plant network. Screenshots may contain customer data: do not store plant folders publicly.

Updates

The program checks GitHub at most once a day for a new version and then shows a notice. Help › Check for updates checks immediately. Nothing is installed automatically: Download opens the ZIP file in the browser.
